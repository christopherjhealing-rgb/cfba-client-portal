# Collateral — Word versions, for editing

One Word file per collateral sheet (plus the go-live runbook), generated
from the HTML masters by `../build-word.mjs`. Same deal as the guidance
notes' Word folder: edit the wording freely — on a phone is fine — and hand
the file back; the changes go into the master it came from, which then
re-renders to the printed PDF.

**What to change:** any wording, any list item, any section.
**What not to worry about:** fonts, colours, spacing, page breaks, photos —
layout comes from the portal template, not from Word.

`[ diagram: … ]` marks a drawing on the printed sheet. Leave the marker
where it is unless you want the diagram moved or removed.

`00 - Go-Live Runbook.docx` is generated from `docs/GO-LIVE-RUNBOOK.md`.
