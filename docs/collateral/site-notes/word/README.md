# Guidance notes — Word versions, for editing

One Word file per published guidance note, generated from the HTML masters.
Edit the wording freely and hand them back; each one goes into the master it
came from, then re-renders to the PDF the portal serves.

**What to change:** any wording, any figure, any bullet. Add or delete
sections. Use the built-in Word styles that are already applied (Heading 1 /
2 / 3, bullets) so the structure survives the trip back.

**What not to worry about:** fonts, colours, spacing, page breaks or where
the photos go. None of that carries over — the printed sheet is laid out by
the portal template, not by Word.

A line reading `[ diagram: ... ]` marks a drawing on the printed sheet that
can't be shown in Word. Leave it where it is unless you want the diagram
moved or removed.
