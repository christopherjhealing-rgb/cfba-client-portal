What they get, and how it feels

Design & feel
  • Photo-hero design across every page, matched dusk photography

  • Title Case across every heading, title and label

Nothing goes quiet, and what's next

The board knows where every job is today
  • The Send? column is now the job's journey to the client, not a yes/no flag
  • SENT — set by hand when the office issues it and puts the files out
  • READY — written by the portal once it HAS the files and the client has been emailed
  • DOWNLOADED — written by the portal when the client actually takes it
  • Job Sent date stamped with the day the client could first get it
  • Forward only: never rewrites a rung reached, never drags a card back, never invents a label
Nothing goes quiet today
  • Evening report, 5pm weekdays — everything that should have reached a client and didn't
  • A lodgement that never made the board · a job issued whose files never arrived
  • A client never told their package was ready · a package ready for days and never opened
  • Board writes Monday wouldn't take · enquiries waiting on an answer
  • Reads "the sync isn't running" first — everything else is only as fresh as the last run
  • A clean day still sends, two lines; preview or send it from /admin any time
Security & resilience
  • All documents in private Australian storage; every download ownership-checked
  • Hardened sign-in: hashed passwords, one-time setup codes, attempt throttling
  • Silent-failure class eliminated — every write verified, every failure visible
  • One bad job can no longer stop the sync for everybody else
  • Data minimisation: declined-lodgement files deleted; 3-month purge honoured
  • WA public holidays (2026–27, verified) in the turnaround maths
  • Privacy notice drafted; collection wording ready for sign-off
Specced and queued (designs agreed, in the register)
  • AI document checker — every Class 10 lodgement checked against our requirements; staff-only findings + a drafted FIR
  • Guidance assistant — answers from our own published notes, hands off to messages
  • Site plan tool v3 — generated elevations from the plan
  • One-off public lodgement — no-login homeowner jobs via magic links
  • Teams-style notification of client messages into a CFBA channel
  • SLIP subscription licence so the cadastre can be used commercially
The shape of the fortnight: the portal lodges faster than email, answers "where's my job?" before the phone rings, and drafts the client's site plan over a real aerial and a real lot boundary. This week it learned the two things that matter most in an office: the board now shows where every job has got to on its way out the door, and if a job goes quiet, we hear the same day.
